📦 Приёмка v4

Накладные → фото палет по накладным → сверка. Спорное исправляешь вручную.

⚙️ Настройки ИИ
Ключ хранится только на этом телефоне и отправляется только в Google. Никому его не показывай. Пока пользуешься, обходной путь (VPN) должен быть включён.

1. Накладные

Снимай сверху, чтобы колонка «Кол-во» целиком попала в кадр. Жёлтые строки проверь по бумаге.

2. Палеты по накладным

Палета №
Снимай так, чтобы этикетки были читаемы: 3-4 стороны, по возможности ближе. После съёмки приложение спросит, к какой накладной и палете отнести снимки (кнопка ↪ на снимке переносит его). Обработаются только новые снимки. После проверки нажми на снимок: найденное обведено красным.

🔎 Товар по штрихкоду

Не понятно, что за товар? Сфоткай штрихкод на коробке: найду позицию в накладных и, если нужно, приму её.

Читаю штрихкод сканером телефона, если его нет — через ИИ (с проверкой контрольной суммы, чтобы не принять выдуманные цифры). Штрихкод коробки (ITF-14) тоже узнаю.

3. Результат

📚 История

«Завершить приёмку» сохраняет результат сюда и очищает экран для новой. Каталог «штук в коробке» остаётся.

Фото отправляются в Google Gemini. На бесплатном уровне Google может использовать присланные данные для улучшения своих сервисов. Убедись, что на работе это разрешено.

📝 Акт расхождений
