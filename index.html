📦 Приёмка v2

Накладная → фото палеты → сверка. Спорное исправляешь вручную.

⚙️ Настройки Gemini
Ключ хранится только на этом телефоне и отправляется только в Google. Никому его не показывай. Пока пользуешься, обходной путь (VPN) должен быть включён.

1. Накладная

Снимай сверху, чтобы колонка «Кол-во» целиком попала в кадр. Жёлтые строки проверь по бумаге.

2. Палета с разных сторон

Снимай так, чтобы этикетки были читаемы: 3-4 стороны, по возможности ближе. Обработаются только новые снимки.

3. Результат

Фото отправляются в Google Gemini. На бесплатном уровне Google может использовать присланные данные для улучшения своих сервисов. Убедись, что на работе это разрешено.
